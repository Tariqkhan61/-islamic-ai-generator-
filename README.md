## ✨ Features

- 📖 **Quran Verses** — Related verses with Urdu translation
- 🕌 **Hadith Collection** — Authentic hadiths with references
- ✍️ **Bayan & Khutbah** — Complete speeches for Friday, Eid, Ramadan
- 📱 **Social Media Posts** — Facebook, Instagram, WhatsApp ready
- 💬 **Islamic Quotes** — Wisdom-filled quotes and Zikr
- 🤲 **Duas & Wazifa** — Masnoon duas with Urdu translation
- 🌙 **Dark Mode** — Comfortable viewing day and night
- 🌐 **Multi-Language** — Urdu, English, Arabic support
- 📱 **Fully Responsive** — Works on mobile, tablet, desktop
